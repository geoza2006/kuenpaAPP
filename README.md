# 🌿 KUENPA APP แอพคืนป่า

**KUENPA** คือแอปพลิเคชันสำหรับช่วยเหลือและอนุรักษ์สัตว์ป่า โดยทำหน้าที่เป็นตัวกลางระหว่างประชาชนและศูนย์ดูแลสัตว์ป่า ช่วยให้ผู้ใช้สามารถแจ้งเหตุเมื่อพบสัตว์ป่าที่ได้รับบาดเจ็บ สัตว์สงวนหรือสัตว์ใกล้สูญพันธุ์ที่อยู่ในสถานที่ที่ไม่เหมาะสม หรืออยู่ในพื้นที่ห่างไกลจากการดูแลของเจ้าหน้าที่

ผู้ใช้สามารถถ่ายรูปสัตว์ ระบุพิกัด และส่งข้อมูลไปยังศูนย์ดูแลสัตว์ป่าที่อยู่ใกล้เคียงได้ ระบบจะแนะนำศูนย์ที่เหมาะสมให้ผู้ใช้เลือก เมื่อส่งรายงานแล้ว เจ้าหน้าที่ของศูนย์จะได้รับแจ้งเหตุและสามารถดำเนินการช่วยเหลือ พร้อมอัปเดตสถานะให้ผู้ใช้ติดตามได้

---

## ✨ ฟีเจอร์หลัก

### 📸 แจ้งเหตุสัตว์ป่า

ผู้ใช้สามารถถ่ายรูปสัตว์ป่าที่พบ พร้อมส่งรายละเอียดของเหตุการณ์เพื่อแจ้งให้เจ้าหน้าที่ทราบ

### 📍 ระบุตำแหน่ง

ระบบสามารถระบุตำแหน่งของผู้ใช้และนำไปใช้ค้นหาศูนย์ดูแลสัตว์ป่าที่อยู่ใกล้เคียง

### 🏥 เลือกศูนย์ดูแลสัตว์ป่า

ระบบแนะนำศูนย์ดูแลสัตว์ป่าที่อยู่ใกล้กับตำแหน่งของผู้ใช้ เพื่อให้สามารถเลือกศูนย์ที่ต้องการส่งรายงานได้

### 🔔 แจ้งเตือนเจ้าหน้าที่

เมื่อผู้ใช้ส่งรายงาน ระบบจะแจ้งข้อมูลไปยังเจ้าหน้าที่ของศูนย์ที่ได้รับเลือก เพื่อให้สามารถดำเนินการช่วยเหลือได้

### 📊 ติดตามสถานะการช่วยเหลือ

ผู้ใช้สามารถตรวจสอบสถานะของรายงาน เช่น รอรับเรื่อง กำลังดำเนินการ หรือดำเนินการเรียบร้อยแล้ว

### 📜 ประวัติการแจ้งเหตุ

ผู้ใช้สามารถดูประวัติการแจ้งเหตุของตนเอง รวมถึงรายละเอียดและสถานะของแต่ละรายการ

### 📰 ข่าวสาร

รวบรวมข่าวสารที่เกี่ยวข้องกับสัตว์ป่า การอนุรักษ์ และเหตุการณ์ต่าง ๆ เพื่อให้ผู้ใช้ติดตามข้อมูลได้

### 📚 เกร็ดความรู้

รวบรวมข้อมูลเกี่ยวกับสัตว์สงวน สัตว์ใกล้สูญพันธุ์ และความรู้เกี่ยวกับการอนุรักษ์สัตว์ป่า

### 🎮 Wildlife Quiz

เกมตอบคำถามเกี่ยวกับสัตว์ป่า เพื่อให้ผู้ใช้สามารถเรียนรู้เกี่ยวกับสัตว์และการอนุรักษ์ผ่านรูปแบบที่สนุกมากขึ้น

### 🔐 ระบบจัดการสิทธิ์

ระบบหลังบ้านสามารถกำหนดและจัดการ Role ของผู้ใช้งานภายในแต่ละศูนย์ดูแลสัตว์ป่า

### 🏢 จัดการศูนย์ดูแลสัตว์ป่า

ผู้ดูแลระบบสามารถเพิ่ม แก้ไข และลบข้อมูลศูนย์ดูแลสัตว์ป่า รวมถึงจัดการข้อมูลที่เกี่ยวข้องกับแต่ละศูนย์

### 🖥️ ระบบหลังบ้าน

ใช้สำหรับจัดการข้อมูลศูนย์ เจ้าหน้าที่ ผู้ใช้งาน รายงานการแจ้งเหตุ และข้อมูลต่าง ๆ ของระบบ

## ⚙️ การติดตั้งและการใช้งาน

### 1. สิ่งที่ต้องเตรียม

ก่อนเริ่มใช้งานโปรเจกต์ ควรติดตั้ง

* Flutter SDK
* Dart SDK
* Android Studio หรือ Visual Studio Code
* Android Emulator หรือโทรศัพท์ Android สำหรับทดสอบ
* Git
* ระบบฐานข้อมูล SQL ที่โปรเจกต์ใช้งาน

ตรวจสอบ Flutter ด้วยคำสั่ง

```bash
flutter doctor
```

---

### 2. Clone Project

ดาวน์โหลดโปรเจกต์จาก Repository

```bash
git clone <repository-url>
```

เข้าสู่โฟลเดอร์โปรเจกต์

```bash
cd Rewild
```

---

### 3. ติดตั้ง Dependencies

ใช้คำสั่ง

```bash
flutter pub get
```

เพื่อดาวน์โหลด Package ที่โปรเจกต์ต้องใช้

---

### 4. ตั้งค่าฐานข้อมูล

สร้างฐานข้อมูล SQL และนำไฟล์ SQL ของโปรเจกต์ไปใช้ในการสร้างตารางที่จำเป็น

ตัวอย่าง

```sql
CREATE DATABASE rewild;
```

จากนั้นตั้งค่าการเชื่อมต่อฐานข้อมูลในส่วน Backend ตามค่าที่กำหนดไว้ในโปรเจกต์

```text
Database Host
Database Port
Database Name
Database Username
Database Password
```

---

### 5. ตั้งค่า API

หากโปรเจกต์มี Backend/API ให้กำหนด URL ของ API ให้ตรงกับ Server ที่ใช้งาน เช่น

```text
API_BASE_URL=<your-api-url>
```

ควรเก็บข้อมูลสำคัญ เช่น Password และ API Key ไว้ในไฟล์ Environment และไม่ควร Commit ข้อมูลเหล่านี้ขึ้น Repository

---

### 6. Run Application

เชื่อมต่อ Emulator หรือโทรศัพท์ Android แล้วใช้คำสั่ง

```bash
flutter run
```

หรือสามารถเลือกอุปกรณ์จาก Android Studio / Visual Studio Code แล้วกด Run ได้

## 👥 User Roles

ระบบรองรับผู้ใช้งานหลายประเภท เช่น

### User

* แจ้งเหตุสัตว์ป่า
* ถ่ายรูปและส่งข้อมูล
* แชร์ตำแหน่ง
* เลือกศูนย์ดูแล
* ติดตามสถานะการช่วยเหลือ
* ดูประวัติการแจ้งเหตุ
* อ่านข่าวสารและเกร็ดความรู้
* เล่น Wildlife Quiz

### Staff

* ดูรายการแจ้งเหตุของศูนย์
* รับเรื่องและดำเนินการช่วยเหลือ
* อัปเดตสถานะของรายงาน
* จัดการข้อมูลที่เกี่ยวข้องกับศูนย์

### Admin

* จัดการข้อมูลศูนย์ดูแลสัตว์ป่า
* เพิ่ม แก้ไข และลบศูนย์
* จัดการ Role ของเจ้าหน้าที่
* จัดการข้อมูลผู้ใช้งานและรายงาน
* ดูและจัดการข้อมูลโดยรวมของระบบ

## 🎯 วัตถุประสงค์ของโครงการ

Rewild ถูกพัฒนาขึ้นเพื่อช่วยลดช่องว่างระหว่างประชาชนและหน่วยงานที่ดูแลสัตว์ป่า ทำให้การแจ้งเหตุสัตว์ป่าที่ต้องการความช่วยเหลือสามารถทำได้ง่ายและรวดเร็วขึ้น พร้อมทั้งช่วยให้เจ้าหน้าที่ได้รับข้อมูลที่สำคัญ เช่น รูปภาพ ตำแหน่ง และรายละเอียดของเหตุการณ์

นอกจากนี้ แอปพลิเคชันยังส่งเสริมความรู้และความตระหนักด้านการอนุรักษ์ผ่านข่าวสาร เกร็ดความรู้ และเกม Quiz เพื่อให้ผู้ใช้สามารถเรียนรู้เกี่ยวกับสัตว์ป่าและการอนุรักษ์ไปพร้อมกับการใช้งานระบบ
